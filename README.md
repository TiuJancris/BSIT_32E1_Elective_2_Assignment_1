# Tiu, Jancris S. | BSIT 32E1

## IT Elective 2 - Assignment 1
**Repository:** `BSIT_32E1_Elective_2_Assignment_1`

This repository contains an ASP.NET Core MVC web application showcasing the comprehensive questions, multiple-choice options, correct answers, and architectural explanations for **Assignment 1** in **IT Elective 2**.

### Topics Covered
1. **Server-Side Rendering (SSR/MVC) vs. Decoupled Web API Architecture**
2. **ControllerBase vs. Controller in ASP.NET Core**
3. **Automatic Model Validation via `[ApiController]`**
4. **RESTful HTTP Status Codes (`201 Created`, `204 No Content`, `200 OK`, `400 Bad Request`)**
5. **RESTful URI Naming Best Practices**
6. **Attribute Routing with `[Route("api/[controller]")]`**
7. **HTTP Verbs: Safety and Idempotency of `GET`**
8. **Action Return Types: `ActionResult<T>` in ASP.NET Core Web API**

---

### How to Run the Application

1. Open a terminal or PowerShell prompt.
2. Navigate to this directory:
   ```bash
   cd BSIT_32E1_Elective_2_Assignment_1
   ```
3. Run the MVC project:
   ```bash
   dotnet run --project AssignmentApp
   ```
4. Open your browser and navigate to the local URL displayed in the console (e.g. `http://localhost:5000` or `https://localhost:5001`).
